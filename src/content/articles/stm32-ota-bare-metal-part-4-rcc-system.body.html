Source: types.h, conf.h, rcc.h, rcc.c, system.c.

In Part 3, main() calls SystemClock_Config() early. This post shows what that init layer actually does — no STM32 HAL clock helpers, only registers.

1. types.h and conf.h

types.h is tiny: shared return codes used by drivers.

typedef enum {
    STATUS_OK = 0x00U,
    STATUS_ERROR = 0x01U,
    STATUS_BUSY = 0x02U,
    STATUS_TIMEOUT = 0x03U
} status_t;

conf.h holds the board clock numbers the rest of the code assumes:

#define TICK_INT_PRIORITY   15U
#define TICK_FREQ_HZ        1000U

#define HSI_VALUE           8000000UL   /* 8 MHz internal RC */
#define HSE_VALUE           8000000UL   /* 8 MHz crystal on Blue Pill */
#define SYSCLK_FREQ_HZ      72000000UL  /* target after PLL */
#define UART1_PCLK_HZ       SYSCLK_FREQ_HZ
#define HSE_STARTUP_TIMEOUT 0x5000U
  • HSI / HSE — both 8 MHz on this board. HSE is the crystal; HSI is the fallback RC.
  • SYSCLK 72 MHz — HSE × PLL×9. UART baud and SysTick 1 ms are computed from this.
  • HSE_STARTUP_TIMEOUT — how long SystemClock_Config waits for HSE/PLL ready before giving up.

2. rcc.h / rcc.c — turn peripheral clocks on

On STM32, a peripheral does nothing until its clock bit is set in RCC. The header maps the RCC block at 0x40021000 and defines which bit enables which APB2 device:

#define RCC ((RCC_TypeDef *)0x40021000)

typedef enum {
    APB2_AFIO   = 1 << 0,
    APB2_PORT_A = 1 << 2,
    APB2_PORT_B = 1 << 3,
    APB2_PORT_C = 1 << 4,
    /* ... */
    APB2_USART1 = 1 << 14
} APB2EN_REG_TypeDef;

The C file is one helper that ORs those bits into RCC_APB2ENR:

void enable_RCC_APB2ENR(unsigned long REG){
    RCC->RCC_APB2ENR.REG |= REG;
}

Example: GPIO init calls something like enable_RCC_APB2ENR(APB2_PORT_C) so PORTC (LED on PC13) gets a clock before you touch its registers. Same idea for APB2_PORT_A + APB2_USART1 before UART. Drivers call this instead of scattering raw bit masks everywhere.

3. SystemClock_Config() — reach 72 MHz

This is the function main() calls. Goal: HSE 8 MHz → PLL ×9 → SYSCLK 72 MHz, APB1 at 36 MHz (max for that bus), then start SysTick.

status_t SystemClock_Config(void)
{
    uint32_t timeout;
    uint32_t cfgr;

    flash_latency_config(2U);   /* Flash needs wait states at 72 MHz */
    flash_prefetch_enable();

    RCC->RCC_CR.REG |= RCC_CR_HSEON;          /* turn crystal on */
    timeout = HSE_STARTUP_TIMEOUT;
    while (((RCC->RCC_CR.REG & RCC_CR_HSERDY) == 0U) && (timeout > 0U)) {
        timeout--;
    }
    if (timeout == 0U) {
        RCC->RCC_CR.REG &= ~RCC_CR_HSEON;
        SystemCoreClock = HSI_VALUE;
        return STATUS_ERROR;                  /* no crystal → stay on HSI */
    }

    cfgr = RCC->RCC_CFGR.REG;
    cfgr &= ~(/* SW, HPRE, PPRE1/2, PLLSRC, PLLMUL, ... */);
    cfgr |= RCC_CFGR_PPRE1_DIV2;              /* APB1 = SYSCLK/2 = 36 MHz */
    cfgr |= RCC_CFGR_PLLSRC_HSE;              /* PLL input = HSE */
    cfgr |= RCC_CFGR_PLLMUL9;                 /* ×9 → 72 MHz */
    RCC->RCC_CFGR.REG = cfgr;

    RCC->RCC_CR.REG |= RCC_CR_PLLON;          /* start PLL */
    /* wait PLLRDY (same timeout pattern) … */

    cfgr = RCC->RCC_CFGR.REG;
    cfgr &= ~RCC_CFGR_SW_Msk;
    cfgr |= RCC_CFGR_SW_PLL;                  /* switch SYSCLK to PLL */
    RCC->RCC_CFGR.REG = cfgr;
    /* wait SWS == PLL … */

    SystemCoreClockUpdate();                  /* refresh global Hz variable */
    if (tick_init(TICK_INT_PRIORITY) != STATUS_OK) {
        return STATUS_ERROR;
    }
    return STATUS_OK;
}
  1. Flash wait states first — at 72 MHz the Flash cannot serve an instruction every cycle with 0 wait states. Configure latency before raising the clock or the core can hard-fault.
  2. Enable HSE, wait ready — if the crystal never locks, return error and leave SystemCoreClock at HSI 8 MHz.
  3. Program PLL — source HSE, multiply ×9, APB1 ÷2 (STM32F103 rule: APB1 max 36 MHz).
  4. Switch SYSCLK to PLL — write SW, then poll SWS until the hardware confirms the switch.
  5. SysTick — tick_init() sets up 1 ms ticks used later for delay_ms() and OTA idle timeout.

4. SystemClock_DeInit and SystemCoreClockUpdate

SystemCoreClockUpdate() reads the live SWS / PLL / AHB prescaler bits and writes the global SystemCoreClock (Hz). Baud-rate math and tick reload use that value.

SystemClock_DeInit() is the reverse path used when jumping to the application: switch back toward HSI, turn PLL/HSE off, clear CFGR, reset Flash ACR bits, then refresh SystemCoreClock. The app can then run its own SystemClock_Config() from a known-clean state instead of inheriting the bootloader’s PLL setup blindly.

5. Takeaway

Order matters: Flash latency → HSE → PLL → switch SYSCLK → SysTick. Peripheral drivers only need enable_RCC_APB2ENR(...) so GPIO/UART clocks are on. Get this wrong and UART baud, delays, and OTA timeouts all drift or fail silently.
