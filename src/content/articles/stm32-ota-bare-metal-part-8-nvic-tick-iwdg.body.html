Source: nvic.c / nvic.h, tick.c / tick.h, iwdg.c / iwdg.h, init.c, msp.c.

These files sit under the same early bring-up path Part 3 showed: main() calls init(), then SystemClock_Config(), GPIO, UART. There is no 3-second “press a key for OTA” window in the current bootloader main.c. SysTick here is for delay_ms(), the OTA UART idle timeout, and the short delay before jumping to the app.

1. init() — first call from main

status_t init(void)
{
    nvic_priority_group_config(NVIC_PRIORITYGROUP_4);

    if (tick_init(TICK_INT_PRIORITY) != STATUS_OK) {
        return STATUS_ERROR;
    }

    msp_init();

    return STATUS_OK;
}
  1. Priority grouping — all 4 priority bits are preemption bits (NVIC_PRIORITYGROUP_4). Do this before enabling IRQs so later priority writes mean the same thing.
  2. SysTick — start a 1 ms tick (see below). After reset the chip is still on HSI 8 MHz; SystemClock_Config() later reloads SysTick once the PLL is at 72 MHz.
  3. msp_init() — board hook (default empty).

init() does not turn on the PLL, GPIO, or UART — those stay in the steps Part 4–6 already covered.

2. MSP hook

/* msp.h */
void msp_init(void);

/* msp.c — default weak stub */
__attribute__((weak)) void msp_init(void)
{
}

Weak so a board file can override it without editing the shared driver. On this Blue Pill bootloader the default is empty: pin/clock work lives in GPIO_Init / Uart1_Init instead.

3. NVIC helpers

nvic.h maps the Cortex-M3 NVIC at 0xE000E100 and SysTick at 0xE000E010, plus the F103 IRQ numbers (USART1_IRQn = 37, …).

void nvic_priority_group_config(nvic_priority_group_t group)
{
    SCB_AIRCR = (SCB_AIRCR & ~(SCB_AIRCR_VECTKEY | SCB_AIRCR_PRIGROUP_MSK))
              | SCB_AIRCR_VECTKEY
              | ((uint32_t)group << 8);
}

void nvic_irq_priority_set(IRQn_Type irqn, uint8_t preempt, uint8_t sub)
{
    uint32_t priority = ((uint32_t)preempt << 4) | ((uint32_t)sub & 0x0FU);
    volatile uint8_t *ipr = (volatile uint8_t *)&NVIC->NVIC_IPR[0];
    ipr[(uint32_t)irqn] = (uint8_t)priority;
}

void nvic_systick_priority_set(uint8_t priority)
{
    SCB_SHPR3 = (SCB_SHPR3 & 0x00FFFFFFUL) | ((uint32_t)priority << 24);
}

void nvic_irq_enable(IRQn_Type irqn)
{
    NVIC->NVIC_ISER[(uint32_t)irqn / 32U].REG =
        (1UL << ((uint32_t)irqn % 32U));
}

void nvic_irq_disable(IRQn_Type irqn)
{
    NVIC->NVIC_ICER[(uint32_t)irqn / 32U].REG =
        (1UL << ((uint32_t)irqn % 32U));
}
  • AIRCR — needs the 0x05FA vector key whenever you change priority grouping.
  • IRQ priority — packed into the NVIC IPR byte (preempt in the high nibble with this grouping).
  • SysTick priority — lives in SCB_SHPR3 bits 31:24, not in NVIC IPR. conf.h sets TICK_INT_PRIORITY to 15 (lowest urgency) so USART RX can preempt the tick if needed.
  • Enable / disable — set the bit in ISER / ICER. Part 6’s Uart1_Init() calls nvic_irq_enable(USART1_IRQn) after programming the USART.

When jumping to the application, bootloader.c clears NVIC enables/pending itself so the app starts from a clean IRQ state — these helpers are for normal runtime bring-up.

4. SysTick — 1 ms time base

From conf.h: TICK_FREQ_HZ = 1000. Reload = SystemCoreClock / 1000.

static volatile uint32_t s_tick;

status_t tick_init(uint8_t priority)
{
    uint32_t reload = SystemCoreClock / TICK_FREQ_HZ;

    if (reload == 0U) {
        return STATUS_ERROR;
    }

    SysTick->STK_CTRL.BITS.ENABLE = 0;
    SysTick->STK_LOAD.BITS.LOAD = reload - 1U;
    SysTick->STK_VAL.REG = 0U;
    SysTick->STK_CTRL.BITS.CLKSOURCE = 1;   /* processor clock */
    SysTick->STK_CTRL.BITS.TICKINT = 1;    /* exception on count=0 */
    nvic_systick_priority_set(priority);
    SysTick->STK_CTRL.BITS.ENABLE = 1;

    return STATUS_OK;
}

void SysTick_Handler(void)
{
    s_tick++;
}

uint32_t tick_get(void)
{
    return s_tick;
}

void delay_ms(uint32_t ms)
{
    const uint32_t start = tick_get();
    while ((tick_get() - start) < ms) {
    }
}
  1. Stop the counter, load reload - 1, clear current value.
  2. Use the CPU clock as the source, enable the tick interrupt, set priority, then enable.
  3. Every 1 ms, SysTick_Handler increments s_tick.
  4. delay_ms is a busy wait on that counter (fine for short pauses).

Where the bootloader uses the tick

  • delay_ms(50) in main.c — short pause after a slot verifies, before jump_to_application() (lets the last UART log bytes finish shifting out).
  • OTA idle timeout — ota_run(OTA_IDLE_TIMEOUT_MS) with OTA_IDLE_TIMEOUT_MS = 5000. Inside ota.c, uart_rx_byte() does deadline = tick_get() + s_idle_limit and returns when no useful RX arrives before that deadline.

Again: current main.c does not wait 3 seconds for a UART key to enter OTA. OTA entry is flag-based, “no valid signed app”, or returning from a previous OTA idle timeout (Part 3).

5. Independent watchdog

#define IWDG ((IWDG_TypeDef *)0x40003000)
#define IWDG_KEY_ENABLE  0xCCCCU
#define IWDG_KEY_RELOAD  0xAAAAU
#define IWDG_KEY_UNLOCK  0x5555U

void Iwdg_Init(void)
{
    RCC->RCC_CSR.REG |= (1UL << 0);           /* LSION */
    while ((RCC->RCC_CSR.REG & (1UL << 1)) == 0U) {
    }                                         /* wait LSIRDY */

    IWDG->IWDG_KR.REG = IWDG_KEY_UNLOCK;      /* 0x5555: allow PR/RLR write */
    IWDG->IWDG_PR.REG = 4U;                   /* /64 */
    IWDG->IWDG_KR.REG = IWDG_KEY_ENABLE;      /* 0xCCCC: start IWDG */
    while (IWDG->IWDG_SR.REG & 0x1U) {
    }                                         /* wait PVU */
    IWDG->IWDG_RLR.REG = 4999U;
    while (IWDG->IWDG_SR.REG & 0x2U) {
    }                                         /* wait RVU */
}

void Iwdg_Feed(void)
{
    IWDG->IWDG_KR.REG = IWDG_KEY_RELOAD;      /* 0xAAAA */
}
  1. Turn on the internal LSI oscillator (~40 kHz) and wait until it is ready.
  2. Unlock the IWDG registers with 0x5555, set prescaler PR = 4 (÷64).
  3. Start the watchdog with 0xCCCC, then program reload RLR = 4999.
  4. Timeout ≈ (RLR + 1) × 64 / 40000 ≈ 8 s if LSI is near 40 kHz. Feed with 0xAAAA before that elapses.

The application main calls Iwdg_Init() once, then Iwdg_Feed() in its 1 Hz loop. Bootloader ota.c calls Iwdg_Feed() while spinning for UART bytes and after erase/program steps so a long transfer does not trip a dog that was already armed. Once started, IWDG cannot be turned off except by reset — which is why feed sites matter during Flash-heavy OTA work.

6. Takeaway

init() sets IRQ grouping + SysTick; NVIC enable is what makes USART1 RX fill the ring buffer; the free-running millisecond counter drives delay_ms and the 5 s OTA idle limit; IWDG is the last-resort reset if software stops feeding during a hang.
