OTA is a simple framed protocol over USART1. This post covers constants, the RX state machine, CRC-16, idle timeout, and ota_run’s outer loop. Command handlers (START / DATA / END) are Part 13.

1. Frame format and constants

#define OTA_FRAME_STX           0x02U
#define OTA_FRAME_ETX           0x03U

#define OTA_CMD_START           0x01U
#define OTA_CMD_DATA            0x02U
#define OTA_CMD_END             0x03U

#define OTA_RSP_ACK             0x06U
#define OTA_RSP_NACK            0x15U

#define OTA_CHUNK_SIZE          256U
#define OTA_MAX_PAYLOAD         (2U + OTA_CHUNK_SIZE)  /* seq + data */

#define OTA_IDLE_TIMEOUT_MS     5000U

On-wire layout:

STX (0x02)
CMD
LEN_L | LEN_H          /* little-endian payload length */
PAYLOAD[len]           /* 0 … OTA_MAX_PAYLOAD bytes */
CRC16_L | CRC16_H      /* CRC over CMD|LEN|PAYLOAD */
ETX (0x03)
  • Host → device: framed START / DATA / END.
  • Device → host: single-byte ACK (0x06) or NACK (0x15) — not framed.
  • DATA payload is typically 2-byte sequence number + up to 256 data bytes.

2. RX state machine

typedef enum {
    RX_WAIT_STX,
    RX_WAIT_CMD,
    RX_WAIT_LEN_L,
    RX_WAIT_LEN_H,
    RX_WAIT_PAYLOAD,
    RX_WAIT_CRC_L,
    RX_WAIT_CRC_H,
    RX_WAIT_ETX
} rx_state_t;

static uint8_t    rx_payload[OTA_MAX_PAYLOAD];
static uint16_t   rx_len;
static uint16_t   rx_index;
static uint8_t    rx_cmd;
static uint16_t   rx_crc_recv;
static rx_state_t rx_state;

ota_receive_frame() consumes one byte per call from the UART ring and advances the state:

RX_WAIT_STX → CMD → LEN_L → LEN_H → PAYLOAD* → CRC_L → CRC_H → ETX
  1. STX — ignore noise until 0x02.
  2. CMD / LEN — store command; build 16-bit length. If len > OTA_MAX_PAYLOAD, reset and return −1.
  3. PAYLOAD — fill rx_payload[]; skip straight to CRC if len == 0.
  4. CRC + ETX — on ETX, recompute CRC over CMD|LEN_L|LEN_H|PAYLOAD; mismatch → reset, −1. Match → return 0 (complete frame ready).

Return values while assembling: 1 = need more bytes, 0 = frame OK, -1 = framing/CRC error, OTA_RX_TIMEOUT (-2) = idle.

3. Frame CRC-16

static uint16_t crc16_update(uint16_t crc, uint8_t data)
{
    crc ^= (uint16_t)data << 8;
    for (int i = 0; i < 8; i++) {
        if (crc & 0x8000U) {
            crc = (uint16_t)((crc << 1) ^ 0x1021U);
        } else {
            crc <<= 1;
        }
    }
    return crc;
}

static uint16_t crc16_calc(const uint8_t *data, uint32_t len)
{
    uint16_t crc = 0xFFFFU;
    for (uint32_t i = 0; i < len; i++) {
        crc = crc16_update(crc, data[i]);
    }
    return crc;
}

CRC-16/CCITT-style: poly 0x1021, init 0xFFFF. Covers the command and payload only — STX/ETX are framing markers, not part of the CRC body. The host tool must use the same polynomial.

4. Byte wait and idle timeout

static int uart_rx_byte(uint8_t *out)
{
    uint32_t deadline = tick_get() + s_idle_limit;

    while ((int32_t)(tick_get() - deadline) < 0) {
        if (uart1_rx_get(out) != 0) {
            /* Refresh idle only when in a frame, or STX arrives */
            if (rx_state != RX_WAIT_STX || *out == OTA_FRAME_STX) {
                deadline = tick_get() + s_idle_limit;
            }
            return 0;
        }
        Iwdg_Feed();
    }
    return OTA_RX_TIMEOUT;
}
  • Reads from Part 6’s IRQ ring buffer — no busy-spin on the USART status register in the foreground for OTA data.
  • Idle deadline refreshes when a frame is in progress, or when STX starts one. Random noise that is not STX does not keep the session alive forever.
  • Default limit is OTA_IDLE_TIMEOUT_MS (5 s). Pure silence → return to main.
  • Every wait loop feeds the IWDG so multi-second transfers do not reset the MCU.

5. ACK / NACK TX

static void ota_tx_ack(void)
{
    ota_tx_byte(OTA_RSP_ACK);
    while ((USART1->USART_SR.REG & USART_SR_TC) == 0U) {
    }
}

static void ota_tx_nack(void)
{
    ota_tx_byte(OTA_RSP_NACK);
    while ((USART1->USART_SR.REG & USART_SR_TC) == 0U) {
    }
}

Polled single-byte replies. Waiting for TC (transmission complete) matters before jump_to_application disables USART — otherwise the host can miss the final ACK.

6. ota_run — outer loop

void ota_run(uint32_t idle_timeout_ms)
{
    s_idle_limit = idle_timeout_ms;
    uart1_rx_flush();
    ota_reset_rx();

    while (1) {
        int st = ota_receive_frame();

        if (st == OTA_RX_TIMEOUT) {
            return;                 /* back to main */
        }

        if (st == 0) {
            ota_process_frame();    /* Part 13 handlers */
            ota_reset_rx();
        } else if (st < 0) {
            ota_tx_nack();          /* bad framing / CRC */
        }
    }
}
  1. Flush UART ring + hardware RX so a previous session’s garbage does not look like STX.
  2. Assemble frames one byte at a time.
  3. Complete frame → ota_process_frame() (START/DATA/END).
  4. Framing/CRC fail → NACK and keep listening (state already reset inside the receiver).
  5. Idle timeout → return. Success path never returns: END jumps to the new app inside the handler.
