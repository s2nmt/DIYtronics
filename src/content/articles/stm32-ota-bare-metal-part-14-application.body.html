Source: application/Src/main.c, application/Src/ota_req.c, application/Inc/ota_req.h.

The application is a thin demo: blink PC13, print a heartbeat over USART1, and when the host sends 'U', write the OTA request flag and reset. The bootloader then sees 0xDEADBEEF and enters OTA immediately — there is no 3-second key window in bootloader/Src/main.c.

1. ota_req.h — flag layout

#define OTA_CONFIG_ADDR     0x0800FC00UL
#define OTA_MAGIC_REQUEST   0xDEADBEEFUL
#define OTA_MAGIC_NONE      0xFFFFFFFFUL
#define OTA_SLOT_APP1       1U
#define OTA_SLOT_APP2       2U
#define OTA_UPDATE_KEY       'U'

typedef struct {
    uint32_t magic;
    uint32_t active_slot;
    uint32_t app_size;
    uint32_t crc32;
    uint32_t version;
} ota_config_t;

void ota_request_enter(void);

Same config page the bootloader uses (OTA_CONFIG_ADDR = last 1 KB of the 64 KB Flash). magic == 0xDEADBEEF means “enter OTA on next boot.”

2. Application main()

int main(void)
{
    __asm volatile("cpsie i" : : : "memory");

    init();
    SystemClock_Config();
    GPIO_Init();
    Uart1_Init();

    printf("app 2 started\r\n");
    printf("Press '%c' for OTA update\r\n", OTA_UPDATE_KEY);

    Iwdg_Init();

    while (1) {
        app_poll_ota_key();
        printf("[%lu] Hello world\r\n", tick_get());
        Iwdg_Feed();
        GPIO_Toggle(GPIOC, 13);
        delay_ms(1000);
    }
}
  1. Enable IRQs — then the same bring-up chain as the bootloader (init / clock / GPIO / UART).
  2. Banner — this build is linked as APP2, so it prints app 2 started and the 'U' hint.
  3. IWDG — start the independent watchdog; the 1 Hz loop feeds it every iteration.
  4. Loop — poll for OTA key, print heartbeat with tick_get(), toggle PC13, delay 1 s.

3. Simple RX path (not the bootloader ring)

The app keeps a tiny IRQ buffer and drains it in the main loop:

static volatile uint8_t s_rx_buf[64];
static volatile uint8_t s_rx_count;

void USART1_IRQHandler(void)
{
    if (USART1->USART_SR.BITS.RXNE) {
        char c = (char)USART1->USART_DR.REG;
        if (s_rx_count < sizeof(s_rx_buf)) {
            s_rx_buf[s_rx_count++] = (uint8_t)c;
        }
    }
}

static void app_poll_ota_key(void)
{
    uint8_t c;

    while (app_take_rx_byte(&c)) {
        if (c == (uint8_t)OTA_UPDATE_KEY) {
            printf("OTA requested, resetting...\r\n");
            delay_ms(50);
            ota_request_enter();
        }
    }
}
  • IRQ pushes bytes into s_rx_buf (drop if full).
  • app_take_rx_byte pops from the front (shifts the rest down).
  • On 'U': log, short delay so the UART line can flush, then ota_request_enter() (does not return).

_write still retargets printf to uart1_write, same as the bootloader.

4. ota_request_enter() — flag + reset

#define APP1_PAYLOAD 0x08005900UL
#define APP2_PAYLOAD 0x0800AB00UL

static uint32_t app_active_slot_guess(void)
{
    if (APP_FLASH_ORIGIN == APP2_PAYLOAD) {
        return OTA_SLOT_APP2;
    }
    return OTA_SLOT_APP1;
}

void ota_request_enter(void)
{
    const ota_config_t *cur = ota_config();
    ota_config_t cfg;

    if (cur->magic != OTA_MAGIC_NONE && cur->magic != OTA_MAGIC_REQUEST) {
        cfg = *cur;   /* keep existing metadata if page already used */
    } else {
        cfg.active_slot = app_active_slot_guess();
        cfg.app_size = 0U;
        cfg.crc32 = 0U;
        cfg.version = 0U;
    }

    cfg.magic = OTA_MAGIC_REQUEST;

    if (flash_unlock() != 0) return;
    if (flash_erase_page(OTA_CONFIG_ADDR) != 0) { flash_lock(); return; }
    if (flash_write_buffer(OTA_CONFIG_ADDR, (const uint8_t *)&cfg, sizeof(cfg)) != 0) {
        flash_lock();
        return;
    }
    flash_lock();
    system_reset();
}
  1. Guess active slot from APP_FLASH_ORIGIN in conf.h (must match the linker FLASH ORIGIN — this tree uses 0x0800AB00 for APP2).
  2. Preserve a live config page if it already holds real metadata; otherwise seed active_slot from the guess.
  3. Set magic = 0xDEADBEEF, erase/program the config page, lock Flash.
  4. Reset via SCB_AIRCR (VECTKEY | SYSRESETREQ) with IRQs masked — never returns.

5. What the bootloader does (no key window)

On reset, bootloader/Src/main.c checks the flag first:

if (ota_flag_is_set()) {
    printf("OTA flag set\r\n");
    (void)ota_flag_clear();
    boot_enter_ota();   /* prints "OTA RX ready", then ota_run() */
}

There is no timed “press U within 3 s” path in the bootloader. Host tools that need OTA while an app is running must spam 'U' to the app (Part 16’s --enter-ota), wait for the reset, then talk to the bootloader once it prints OTA RX ready.

6. Where this image lives

Payload vectors sit at slot base + 256-byte IMG1 header:

  • APP1 payload — 0x08005800 + 0x100 = 0x08005900
  • APP2 payload — 0x0800AA00 + 0x100 = 0x0800AB00 (this repo’s default linker / APP_FLASH_ORIGIN)

Signing wraps the raw .bin with that 256-byte header; the slot image base is APP1_START / APP2_START. Part 15 covers the linker and startup details.
