After clocks are up, main() calls GPIO_Init(). On this board that sets up three pins the bootloader actually uses: PA9 / PA10 for USART1, and PC13 for the Blue Pill LED.

1. How pins are mapped in hardware

Each GPIO port is a block of registers. The header points at the F103 addresses:

#define GPIOA ((GPIO_TypeDef *)0x40010800)
#define GPIOB ((GPIO_TypeDef *)0x40010C00)
#define GPIOC ((GPIO_TypeDef *)0x40011000)

Important registers for this driver:

  • CRL / CRH — pin mode. Pins 0–7 live in CRL; pins 8–15 in CRH. Each pin owns 4 bits: MODE (2) + CNF (2).
  • IDR — read pin level (input).
  • ODR — current output data (also used to know “is the pin high or low?”).
  • BSRR — atomic set/reset. Low 16 bits set a pin; high 16 bits reset it. Safer than read-modify-write on ODR when IRQ can interrupt you.

2. Mode constants — what the 4 bits mean

F103 packs CNF and MODE into one nibble. The enum builds that nibble:

typedef enum {
    GPIO_MODE_INPUT_FLOAT              = (1 << 2) | 0,  /* CNF=01, MODE=00 */
    GPIO_MODE_OUTPUT_OPEN_50MHz        = (1 << 2) | 3,  /* CNF=01, MODE=11 */
    GPIO_MODE_AF_OUTPUT_PUSHPULL_50MHz = (2 << 2) | 3,  /* CNF=10, MODE=11 */
    /* … other speed / CNF combinations … */
} GPIO_MODE;
  • MODE — 00 = input; 01/10/11 = output at 10 / 2 / 50 MHz max slew.
  • CNF (input) — analog / floating / pull-up-down.
  • CNF (output) — push-pull, open-drain, or alternate-function versions of those.

This project needs three concrete modes:

  • PA9 — AF push-pull 50 MHz (USART1 TX).
  • PA10 — floating input (USART1 RX).
  • PC13 — open-drain output 50 MHz (onboard LED; Blue Pill LED is wired active-low on an open-drain-friendly pin).

3. GPIO_Init() — what main() calls

void GPIO_Init(void)
{
    enable_RCC_APB2ENR(APB2_PORT_A | APB2_PORT_C | APB2_USART1);

    GPIO_Mode(GPIOA, 9,  GPIO_MODE_AF_OUTPUT_PUSHPULL_50MHz);
    GPIO_Mode(GPIOA, 10, GPIO_MODE_INPUT_FLOAT);
    GPIO_Mode(GPIOC, 13, GPIO_MODE_OUTPUT_OPEN_50MHz);
}
  1. Enable clocks — PORTA, PORTC, and USART1 on APB2 (the helper from Part 4). Without this, writes to GPIO/USART registers do nothing useful.
  2. Configure TX/RX pins — so Part 6’s Uart1_Init() can talk over the wire. GPIO owns the pin mux; UART owns baud and IRQ.
  3. Configure LED — PC13 ready for GPIO_Toggle / GPIO_Write as a heartbeat.

4. GPIO_Mode() — write one pin’s nibble

void GPIO_Mode(volatile GPIO_TypeDef* GPIO, uint8_t GPIO_PIN, GPIO_MODE Mode)
{
    unsigned int reset = ~0, set = 0;

    reset &= ~(((1 << 4) - 1) << ((GPIO_PIN % 8) * 4));
    set   |= Mode << ((GPIO_PIN % 8) * 4);

    if (GPIO_PIN > 7) {
        GPIO->CRH.REG &= reset;
        GPIO->CRH.REG |= set;
    } else {
        GPIO->CRL.REG &= reset;
        GPIO->CRL.REG |= set;
    }
}

Walkthrough for PC13:

  1. Pin 13 → use CRH (because > 7).
  2. Inside CRH, pin 13 is the slot for “pin index 5” of that register: (13 % 8) * 4 = 20 — so bits 20–23.
  3. reset clears those 4 bits; set writes the new MODE+CNF nibble.
  4. Other pins in the same register stay untouched.

Same math for PA9 (CRH, nibble for pin 1) and PA10 (CRH, nibble for pin 2).

5. Read / Write / Toggle

5.1 GPIO_Read

GPIO_STATE GPIO_Read(volatile GPIO_TypeDef* GPIO, uint8_t PIN){
    return (GPIO->IDR.REG >> PIN) & 1;
}

Shift the IDR bit for that pin and mask to 0/1. Useful for inputs; the bootloader path mostly uses write/toggle for the LED.

5.2 GPIO_Write

void GPIO_Write(volatile GPIO_TypeDef* GPIO, uint8_t PIN, GPIO_STATE state){
    if (((GPIO->ODR.REG >> PIN) & 1) == state) return;

    switch (state) {
    case GPIO_RESET:
        GPIO->BSRR.REG = (1UL << (16 + PIN));  /* reset bit in high half */
        break;
    case GPIO_SET:
        GPIO->BSRR.REG = (1UL << PIN);          /* set bit in low half */
        break;
    }
}
  • If ODR already matches the requested state, return (no bus write).
  • Otherwise use BSRR: set = bit PIN; reset = bit 16+PIN. One write, atomic.

On Blue Pill, LED on means drive PC13 low (active-low), so “LED on” is typically GPIO_Write(GPIOC, 13, GPIO_RESET).

5.3 GPIO_Toggle

void GPIO_Toggle(volatile GPIO_TypeDef* GPIO, uint8_t PIN){
    GPIO->BSRR.REG = (1UL << (16 * ((GPIO->ODR.REG >> PIN) & 1) + PIN));
}

Read current ODR bit. If it is 0, write set (1 << PIN). If it is 1, write reset (1 << (16+PIN)). The app’s 1 Hz heartbeat loop calls this on PC13.

6. Why mention GPIO here

This GPIO layer is only an introduction. It is not part of the OTA protocol. In this project we use PC13 simply as a status signal (heartbeat / life LED) so you can see the MCU is running while bring-up and the main loop execute.
