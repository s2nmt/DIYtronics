A slot is not “whatever got written over UART.” It is a fixed layout: 256-byte signed header, then payload. boot_verify_slot is the gate main and OTA END both must pass before a jump.

1. IMG1 header (256 bytes)

#define IMG_MAGIC               0x494D4731UL   /* "IMG1" */
#define IMG_TYPE_APP            1U
#define IMG_HEADER_SIZE         0x00000100UL   /* 256 B, fixed */

typedef struct __attribute__((packed)) {
    uint32_t magic;
    uint32_t image_type;
    uint32_t payload_offset;
    uint32_t payload_size;
    uint32_t version;
    uint32_t reserved0;
    uint8_t  sha256[32];
    uint8_t  signature[64];   /* ECDSA P-256 r||s */
    uint8_t  reserved1[32];
} img_header_t;

Slot layout:

[slot_base + 0]                img_header_t   (256 bytes)
[slot_base + payload_offset]   app payload    (vector table + code)
  • magic — ASCII IMG1 as a little-endian word.
  • payload_offset — normally 0x100 (right after the header). App linker ORIGIN = slot_base + 0x100 (e.g. APP1 → 0x08005900).
  • sha256 — hash of the payload only (not the header).
  • signature — ECDSA P-256 over that hash, 64 bytes r||s.

A compile-time assert ensures sizeof(img_header_t) <= 256.

2. img_header_parse

int img_header_parse(uint32_t slot_base, const img_header_t **out_hdr)
{
    const img_header_t *hdr = (const img_header_t *)slot_base;

    if (out_hdr == NULL) {
        return -1;
    }
    if (hdr->magic != IMG_MAGIC) {
        return -1;
    }
    if (hdr->image_type != IMG_TYPE_APP) {
        return -2;
    }
    if (hdr->payload_offset < IMG_HEADER_SIZE) {
        return -3;
    }
    if (hdr->payload_size == 0U) {
        return -4;
    }

    *out_hdr = hdr;
    return 0;
}
  1. Map the slot base as an img_header_t in place (no copy).
  2. Reject wrong magic, non-APP type, offset that would overlap the header, or zero size.
  3. Return distinct negative codes so serial logs / OTA can tell why parse failed.

3. img_payload_bounds

int img_payload_bounds(uint32_t slot_base, uint32_t slot_size,
                       const img_header_t *hdr,
                       uint32_t *out_addr, uint32_t *out_size)
{
    uint32_t payload_addr = slot_base + hdr->payload_offset;
    uint32_t payload_end  = payload_addr + hdr->payload_size;

    if (payload_end < payload_addr) {
        return -2;   /* overflow */
    }
    if (payload_end > (slot_base + slot_size)) {
        return -3;   /* past end of slot */
    }

    *out_addr = payload_addr;
    *out_size = hdr->payload_size;
    return 0;
}

Stops a malicious or corrupt header from claiming a payload that walks past the 20.5 KB slot into the other bank or the OTA config page.

4. boot_verify_slot — SHA-256 + ECDSA

int boot_verify_slot(uint32_t slot_base, uint32_t slot_size, uint32_t *out_jump_addr)
{
    const img_header_t *hdr;
    uint8_t computed[32];
    uint32_t payload_addr;
    uint32_t payload_size;
    int rc;

    if (out_jump_addr == NULL) {
        return -1;
    }

    rc = img_header_parse(slot_base, &hdr);
    if (rc != 0) {
        return rc;
    }

    rc = img_payload_bounds(slot_base, slot_size, hdr, &payload_addr, &payload_size);
    if (rc != 0) {
        return rc;
    }

    if (!app_is_valid_at(payload_addr)) {
        return -10;
    }

    crypto_sha256((const uint8_t *)payload_addr, payload_size, computed);

    if (crypto_memcmp_ct(computed, hdr->sha256, 32U) != 0) {
        return -11;
    }

    if (crypto_ecdsa_p256_verify(bootloader_pubkey, computed, hdr->signature) != 1) {
        return -12;
    }

    *out_jump_addr = payload_addr;
    printf("BL: ok %08lX\r\n", (unsigned long)payload_addr);
    return 0;
}
  1. Parse + bounds — header must be well-formed and fit the slot.
  2. Vector sanity — Part 10’s app_is_valid_at (−10 if SP/entry look wrong or wrong-linked).
  3. SHA-256 — hash the payload bytes in Flash; compare to hdr->sha256 with constant-time crypto_memcmp_ct (−11 on mismatch).
  4. ECDSA P-256 — verify signature against the embedded public key (−12 on failure).
  5. Success — write the payload address as the jump target and log BL: ok ….

5. Public key

boot_pubkey.c is generated by tools/keygen.py (Part 2). It exports a 64-byte uncompressed P-256 public key (X||Y) that crypto_ecdsa_p256_verify consumes. Only images signed with the matching private key pass step 4.

6. Who calls this

  • main → boot_pick_slot — tries active then inactive; first boot_verify_slot == 0 wins.
  • OTA END handler — after CRC32 of the written bytes matches, verifies the inactive slot before flipping active_slot and jumping.

Error codes (−1…−4 parse/bounds, −10 vectors, −11 hash, −12 signature) make UART bring-up easier without a debugger.
