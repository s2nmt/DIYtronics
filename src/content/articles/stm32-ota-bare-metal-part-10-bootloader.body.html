Part 3 covered the high-level main() decision tree. This post is the support layer behind it: Flash map, A/B slot helpers, the OTA request flag, vector-table sanity checks, and the irreversible jump into an application.

1. Flash map and config struct

The header documents the 64 KB layout:

/* Flash layout (64 KB total)
 *
 * 0x08000000  22 KB   Bootloader
 * 0x08005800  20.5 KB APP1 slot (header + payload)
 * 0x0800AA00  20.5 KB APP2 slot
 * 0x0800FC00   1 KB   OTA config
 */
#define BOOTLOADER_START        0x08000000UL
#define BOOTLOADER_SIZE         0x00005800UL  /* 22 KB */

#define APP1_START              0x08005800UL
#define APP1_SIZE               0x00005200UL  /* 20.5 KB (20992 B) */

#define APP2_START              0x0800AA00UL
#define APP2_SIZE               0x00005200UL  /* 20.5 KB — same as APP1 */

#define OTA_CONFIG_ADDR         0x0800FC00UL  /* last 1 KB page */

#define OTA_MAGIC_REQUEST       0xDEADBEEFUL
#define OTA_MAGIC_NONE          0xFFFFFFFFUL

#define OTA_SLOT_APP1           1U
#define OTA_SLOT_APP2           2U

Each app slot holds a 256-byte IMG1 header plus payload (vector table + code). The last Flash page stores ota_config_t:

typedef struct {
    uint32_t magic;
    uint32_t active_slot;   /* OTA_SLOT_APP1 or OTA_SLOT_APP2 */
    uint32_t app_size;
    uint32_t crc32;
    uint32_t version;
} ota_config_t;
  • magic — 0xDEADBEEF means “enter OTA on next boot”; cleared to 0xFFFFFFFF after the bootloader honors it.
  • active_slot — which bank is currently the live app (1 or 2). Virgin Flash reads as 0xFF…, treated as APP1.

2. Active / inactive slot helpers

static const ota_config_t *ota_config(void)
{
    return (const ota_config_t *)OTA_CONFIG_ADDR;
}

uint32_t app_get_active_start(void)
{
    if (ota_config()->active_slot == OTA_SLOT_APP2) {
        return APP2_START;
    }
    return APP1_START;
}

uint32_t app_get_inactive_start(void)
{
    if (app_get_active_start() == APP2_START) {
        return APP1_START;
    }
    return APP2_START;
}
  1. Active — the slot main prefers when verifying / jumping.
  2. Inactive — the only bank OTA is allowed to erase and program (A/B swap).
  3. If config is erased, active_slot is not APP2 → default APP1.

3. app_is_valid_at — vector-table sanity

Before crypto (and again mid-OTA), the bootloader checks that a payload address looks like a Cortex-M vector table linked for this slot:

int app_is_valid_at(uint32_t app_addr)
{
    uint32_t slot_base;
    uint32_t slot_end;
    uint32_t sp;
    uint32_t entry;

    if (slot_bounds_for_payload(app_addr, &slot_base, &slot_end) != 0) {
        return 0;
    }

    sp    = *(volatile uint32_t *)app_addr;
    entry = *(volatile uint32_t *)(app_addr + 4U);

    if ((sp & 0x2FFE0000UL) != 0x20000000UL) {
        return 0;   /* MSP must be in SRAM */
    }
    if (entry < app_addr || entry >= slot_end) {
        return 0;   /* Reset_Handler outside this slot */
    }
    if ((entry & 1U) == 0U) {
        return 0;   /* Thumb bit required */
    }
    return 1;
}
  • slot_bounds_for_payload maps the address into APP1 or APP2 (payload must sit at or after slot_base + 256).
  • SP mask is the classic STM32 “is this RAM?” check.
  • An image signed for APP1 but written into APP2 fails here — OTA aborts early instead of finishing a useless transfer.

app_find_boot_addr() tries active payload then inactive payload with this check only (no crypto). Full boot uses boot_verify_slot from Part 11.

4. OTA flag — set by the app, cleared by the bootloader

int ota_flag_is_set(void)
{
    return ota_config()->magic == OTA_MAGIC_REQUEST;
}

int ota_flag_clear(void)
{
    const ota_config_t *cur = ota_config();
    ota_config_t cfg;

    if (!ota_flag_is_set()) {
        return 0;
    }

    cfg.magic       = OTA_MAGIC_NONE;
    cfg.active_slot = (cur->active_slot == OTA_SLOT_APP2)
                        ? OTA_SLOT_APP2 : OTA_SLOT_APP1;
    cfg.app_size    = cur->app_size;
    cfg.crc32       = cur->crc32;
    cfg.version     = cur->version;

    /* unlock → erase OTA_CONFIG_ADDR → write cfg → lock */
    …
}
  1. App writes magic = 0xDEADBEEF (preserving active_slot) and resets — see Part 14.
  2. Bootloader sees the flag, clears it (erase + rewrite the config page), then enters ota_run.
  3. Clearing preserves which slot is active so a failed OTA still boots the previous good image.

There is no 3-second UART key-wait in main.c. Forced OTA is only via this flag (or no valid signed image).

5. jump_to_application

void jump_to_application(uint32_t app_addr)
{
    uint32_t app_sp    = *(volatile uint32_t *)app_addr;
    uint32_t app_entry = *(volatile uint32_t *)(app_addr + 4U);
    uint32_t i;

    if (!app_is_valid_at(app_addr)) {
        return;
    }

    (void)SystemClock_DeInit();

    USART1->USART_CR1.REG = 0U;
    USART1->USART_CR2.REG = 0U;
    USART1->USART_CR3.REG = 0U;

    SysTick->STK_CTRL.REG = 0U;
    SysTick->STK_LOAD.REG = 0U;
    SysTick->STK_VAL.REG  = 0U;
    SCB_ICSR = SCB_ICSR_PENDSTCLR | SCB_ICSR_PENDSVCLR;

    cpu_disable_irq();

    for (i = 0U; i < 8U; i++) {
        NVIC_ICER(i) = 0xFFFFFFFFUL;
        NVIC_ICPR(i) = 0xFFFFFFFFUL;
    }

    SCB_VTOR = app_addr;
    cpu_dsb_isb();

    cpu_set_msp(app_sp);
    cpu_set_control(0U);   /* privileged Thread, MSP */
    cpu_dsb_isb();

    __asm volatile("bx %0" : : "r"(app_entry) : );

    while (1) {
    }
}
  1. Re-validate — refuse to jump a bad vector table.
  2. De-init shared hardware — clocks back toward a clean HSI state, USART1 off, SysTick off, clear PendSV/SysTick pending.
  3. Mask IRQs — cpsid i, clear all NVIC enable and pending registers so a leftover USART IRQ cannot fire with the app’s vector table mid-setup.
  4. Relocate vectors — SCB_VTOR = app_addr (payload base, not slot base).
  5. Hand off — load MSP from word 0, bx to Reset_Handler (word 1). Does not return on success.

If validation fails, the function returns and main falls through to OTA.

6. How main.c uses this layer

if (ota_flag_is_set()) {
    (void)ota_flag_clear();
    boot_enter_ota();          /* ota_run(); may return on idle */
}

if (boot_pick_slot(&slot_base, &slot_size, &jump_addr) == 0) {
    delay_ms(50);
    jump_to_application(jump_addr);
} else {
    printf("No valid signed app\r\n");
}

boot_enter_ota();

while (1) {
    if (boot_pick_slot(...) == 0) {
        delay_ms(50);
        jump_to_application(jump_addr);
    }
    boot_enter_ota();
}

boot_pick_slot calls boot_verify_slot on active then inactive (Part 11). Flow in one line: OTA flag → ota_run; then pick slot → jump; else ota; loop.
