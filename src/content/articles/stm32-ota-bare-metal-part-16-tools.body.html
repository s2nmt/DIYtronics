Source: bootloader/tools/main.py, sign_image.py, serial.py, keygen.py (Part 2).

Host side of the OTA path: build an IMG1-signed slot image, tell a running app to reset into the bootloader, then push START / DATA / END frames over USART1 at 115200.

1. Setup

cd bootloader/tools
pip install -r requirements.txt   # pyserial, ecdsa

Typical upload (sign + force OTA from the app + transfer):

python main.py COM6 path/to/app.bin --sign --enter-ota

2. sign_image.py — raw payload → slot image

IMG_MAGIC = 0x494D4731          # "IMG1"
IMG_HEADER_SIZE = 0x100

def build_header(payload: bytes, version: int) -> bytes:
    digest = sha256(payload)
    sk = derive_signing_key()   # from keygen.py (same seed as Part 2)
    signature = sk.sign_digest(
        digest,
        sigencode=lambda r, s, order: r.to_bytes(32, "big") + s.to_bytes(32, "big"),
    )

    hdr = struct.pack(
        "<6I",
        IMG_MAGIC,
        IMG_TYPE_APP,       # 1
        PAYLOAD_OFFSET,     # 0x100
        len(payload),
        version,
        0,
    )
    hdr += digest           # 32 B SHA-256
    hdr += signature        # 64 B r||s
    hdr += b"\x00" * 32
    hdr += b"\x00" * (IMG_HEADER_SIZE - len(hdr))
    return hdr

signed = build_header(payload, version) + payload
  1. Read the raw app .bin (linked at slot+0x100 — Part 15).
  2. SHA-256 the payload; ECDSA P-256 sign the digest with derive_signing_key().
  3. Pack the 256-byte header (magic, type, offset, size, version, digest, sig, pad).
  4. Write header || payload — that whole blob is what UART OTA programs into the inactive slot.

CLI: python sign_image.py app.bin -o app_signed.bin --version 1. main.py --sign shells out to the same script and uploads the *_signed.bin.

3. serial.py — quick UART monitor

A small helper (not required for upload). Opens a hardcoded COM6 @ 115200, optionally sends UPDATE\r\n with --send-update, and prints whatever the MCU sends. Note the path hack: the file is named serial.py, so it removes its own directory from sys.path before import serial so PySerial wins — main.py does the same.

4. main.py — OTA client

4.1 Frame format (matches ota.h)

STX = 0x02
ETX = 0x03
CMD_START, CMD_DATA, CMD_END = 0x01, 0x02, 0x03
RSP_ACK, RSP_NACK = 0x06, 0x15
CHUNK_SIZE = 256

def build_frame(cmd: int, payload: bytes) -> bytes:
    body = bytes([cmd]) + struct.pack("<H", len(payload)) + payload
    crc = crc16_ccitt(body)
    return bytes([STX]) + body + struct.pack("<H", crc) + bytes([ETX])

CRC16-CCITT over cmd || length || payload. Firmware CRC32 (for START) uses the reflected poly 0xEDB88320 over the whole upload blob.

Flow matches Part 14: PC sees the app banner → writes 'U' a few times → app prints OTA requested, resetting... → bootloader prints OTA flag set then OTA RX ready. Without --enter-ota, the tool only waits for an already-open OTA session (OTA RX ready within 15 s).

4.3 Upload sequence

if sign:
    upload_path = sign_firmware_file(firmware_path, version=...)

fw = load_firmware(upload_path)   # .bin or Intel HEX
fw_crc = crc32_firmware(fw)

# optional enter_ota_mode(...)
send_frame(..., CMD_START, pack("<II", fw_size, fw_crc), ...)

seq = 0
while offset < fw_size:
    chunk = fw[offset : offset + 256]
    send_frame(..., CMD_DATA, pack("<H", seq) + chunk, ...)
    seq += 1

send_frame(..., CMD_END, b"", ...)
  1. Optional sign — produce *_signed.bin via sign_image.py.
  2. Open COM without toggling DTR/RTS (avoids accidental MCU reset on port open).
  3. Background reader — UartLogReader thread demuxes MCU printf text from ACK/NACK bytes.
  4. START — little-endian size + CRC32 of the signed image.
  5. DATA — 256-byte chunks with a 16-bit sequence number; retries on timeout/NACK.
  6. END — empty payload; if ACK is lost but the MCU already printed OTA OK / app started, treat as success.

5. CLI flags

  • port / firmware — required (e.g. COM3, app.bin or .hex).
  • --baud — default 115200 (must match Part 6).
  • --sign / --version N — sign before upload.
  • --enter-ota — drive the app’s 'U' path into the flag-based OTA entry.
  • --timeout / -v — ACK wait and hex dumps.

6. Series wrap-up

Full path: keys (keygen.py) → signed IMG1 → bare-metal drivers → dual-slot bootloader → UART protocol → app request flag → this host tool. Clone STM32F103C8T6-ota-base-metal, flash the bootloader once with ST-Link, and iterate apps over serial.
